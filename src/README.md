# Calculadora de Resistencias (Java Swing)

Aplicación de escritorio desarrollada en Java para calcular el valor óhmico y la tolerancia de resistencias eléctricas mediante el código de colores estándar.

## Características Principales

* **Cálculo Preciso:** Lógica basada en la tabla estándar de resistencias de 4 bandas.
* **Interfaz Dinámica:** Dibujo en tiempo real de la resistencia mediante `Java2D`, representando gráficamente los colores seleccionados.
* **Auto-formateo:** Conversión inteligente de unidades (Ω, kΩ, MΩ) con eliminación de decimales innecesarios.
* **Arquitectura Limpia:** Uso de `Enums` para la gestión de datos y separación de responsabilidades entre el modelo de datos y la interfaz gráfica.

## Tecnologías Utilizadas

* **Lenguaje:** Java 17+
* **Interfaz Gráfica:** Java Swing (AWT, Java2D)
* **IDE:** IntelliJ IDEA
* **Gestión de Versiones:** Git & GitHub
